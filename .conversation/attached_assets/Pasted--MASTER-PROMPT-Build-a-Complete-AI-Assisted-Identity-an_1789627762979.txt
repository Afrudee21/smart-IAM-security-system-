# MASTER PROMPT

## Build a Complete AI-Assisted Identity and Access Management (IAM) Security Platform

You are an expert **Full-Stack Developer, IAM Engineer, Cybersecurity Engineer, UI/UX Designer, Database Engineer, and QA Engineer**.

Your task is to build a **complete, fully functional, production-style academic project** from scratch.

The project must not be a simple login/register application. It must demonstrate real **Identity and Access Management (IAM)** concepts including authentication, authorization, RBAC, permissions, MFA, session management, audit logging, login-risk analysis, security alerts, and administrative monitoring.

Build everything inside this Replit project and make the final application runnable directly from Replit.

---

# 1. PROJECT TITLE

Use the following official project title:

**AI-Assisted Identity and Access Management System with Role-Based Access Control and Risk Monitoring**

Short name:

**Smart IAM Security Platform**

---

# 2. PROJECT OBJECTIVE

Develop a web-based IAM platform that allows an organization to:

* Register and authenticate users
* Securely store passwords
* Assign roles to users
* Define granular permissions
* Enforce Role-Based Access Control
* Support Multi-Factor Authentication
* Manage user sessions
* Detect suspicious login patterns using a rule-based risk engine
* Calculate a login risk score
* Generate security alerts
* Maintain detailed audit logs
* Allow administrators to manage users, roles, permissions and security events
* Display security information through a professional dashboard

The final system should feel like a **small enterprise IAM product**, not a classroom login demo.

# 16. RISK ANALYSIS ENGINE

Build a safe, simulated risk engine.

This is NOT an offensive cybersecurity tool.

The purpose is to analyze synthetic login events.

Create a risk score:

```text
0–30
NORMAL

31–60
MONITOR

61–80
WARNING

81–100
CRITICAL
```

Risk factors can include:

### Failed login attempts

```text
0 failed attempts → +0
1–2 → +10
3–4 → +20
5+ → +35
```

### New device

```text
Known device → +0
New device → +15
```

### Unusual login time

```text
Normal hours → +0
Unusual hours → +10
```

### Rapid repeated attempts

```text
Normal → +0
Suspicious frequency → +15
```

### Previously unseen IP

```text
Known → +0
New → +10
```

Keep total score between:

```text
0 and 100
```
